# منصة مجموعة FUJI — Fujihk

**متجر هندسي وتطبيق للعملاء وتطبيق FUJI ADMIN**

**موقع عام · تطبيقان غير منشورين · شيفرة التطبيق خاصة**

[المتجر المنشور](https://fujihk.net/) · [دراسة المشروع](https://mohamedabderrehmane.netlify.app/ar/projects/fujihk/) · [English](README.md)

![المتجر العام لمجموعة FUJI](docs/images/00-home.jpg)

FUJI منصة مترابطة للمنتجات والعمليات: كتالوج هندسي عام، وتطبيق تسوق وخدمات للعملاء، وتطبيق إدارة للفريق، ولوحة إدارة عليا خاصة على الويب. يستخدم تطبيقا الهاتف Expo وReact Native وTypeScript ويتصلان بواجهة المنصة البرمجية.

## تطبيقا الهاتف

### تطبيق FUJI للعملاء

يجمع تطبيق العملاء البحث عن المنتجات وتصفحها وتفاصيلها والمفضلة والسلة والدفع وسجل الطلبات ضمن تجربة هاتف. كما يربط العملاء بمعلومات الشركة والمشاريع وطلبات الأسعار وقوائم الفحص وتتبع الشحنات والأدلة والفعاليات والدعم.

### FUJI ADMIN

يقدم تطبيق الفريق لوحة تعتمد على الصلاحيات لبعض العمليات: تعديل المنتجات وإدخالها بالجملة ورفع الصور وإدارة العلامات والفئات والعملاء والشحنات والأدلة وجدول المعارض والإعدادات وصلاحيات المشرفين الفرعيين. وتتحدد الوحدات الظاهرة وفق صلاحيات المشرف المسجل.

> لم يُنشر أي من التطبيقين على Google Play أو Apple App Store. هذا مستودع عرض وليس صفحة متجر أو تنزيل.

## بنية الويب والهاتف

- المتجر العام: استكشاف الكتالوج وتفاصيل المنتج والسلة ومداخل حساب العميل.
- تطبيق FUJI للعملاء: تطبيق Expo وReact Native للتسوق وخدمات العملاء.
- FUJI ADMIN: تطبيق Expo وReact Native منفصل لعمليات الفريق.
- إدارة الويب الخاصة: مسارات الإدارة العليا الأوسع.
- تربط واجهة API والسجلات المشتركة بين التطبيقات.

راجع [مخطط البنية](docs/architecture.svg) و[دراسة تطبيقي الهاتف](docs/mobile-apps.ar.md) و[معرض الصور](docs/gallery.ar.md) و[دراسة المشروع](docs/case-study.ar.md). تبقى الشيفرة والوصول الداخلي للإدارة خاصين. يميز المعرض بين صور الموقع العام ومعاينات واجهات الهاتف المستندة إلى الشيفرة.
