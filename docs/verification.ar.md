# التحقق والأدلة

- راجعت مسارات تطبيق العملاء وFUJI ADMIN وتعاريف التنقل وعملاء API وحساب الصلاحيات وبيانات الحزم في مساحة المشروع الخاصة.
- تأكدت أن التطبيقين مبنيان باستخدام Expo وReact Native وأنهما غير منشورين في متجري التطبيقات، بحسب إفادة مالك المشروع.
- راجعت صور الموقع العام وأنشأت أربع رسومات معاينة موضحة لواجهات الهاتف بالاستناد إلى بنية الشاشات وعناصر التصميم في الشيفرة.
- تستخدم صور الهاتف بيانات اصطناعية وليست لقطات من نسخة تطبيق تعمل فعلياً.
- لم أبنِ التطبيقين ولم أقدمهما للمتاجر ولم أدخل إلى الإدارة الحية أو أجرّب بيانات الإنتاج ضمن هذا التحديث التوثيقي.
- لم أضف شيفرة التطبيقات أو بيانات الدخول أو قواعد البيانات الخاصة أو ملفات التثبيت أو صور الإدارة الداخلية إلى مستودع العرض.
